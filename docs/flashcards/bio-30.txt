bio30-021	<b>Homeostasis</b>: what is it?	<b>Homeostasis</b> is the <b>maintenance of a relatively stable internal environment</b> (temperature, blood glucose, water content, pH, ion levels) despite changes outside.	ImatPath Biology term
bio30-013	<small>Temperature</small><br><b>Hair lies flat</b><br><i>If the body is too cold?</i>	Hair stands up (traps a layer of air, but little effect in humans)	ImatPath Biology recall
bio30-014	<small>Temperature</small><br><b>Behaviour: seek shade, drink</b><br><i>If the body is too cold?</i>	<b>Non-shivering thermogenesis</b> (brown fat). Behaviour: put on clothes	ImatPath Biology recall
bio30-015	<small>Blood glucose</small><br><b>Released when</b><br><i>Insulin (β cells) · Glucagon (α cells)?</i>	<b>Insulin (β cells):</b> Blood glucose is <b>high</b><br><b>Glucagon (α cells):</b> Blood glucose is <b>low</b>	ImatPath Biology recall
bio30-016	<small>Blood glucose</small><br><b>Effect on the liver and muscle</b><br><i>Insulin (β cells) · Glucagon (α cells)?</i>	<b>Insulin (β cells):</b> Cells take up glucose. Glucose → <b>glycogen</b> (<b>glycogenesis</b>)<br><b>Glucagon (α cells):</b> Glycogen → glucose (<b>glycogenolysis</b>) and <b>gluconeogenesis</b> (new glucose from amino acids and glycerol)	ImatPath Biology recall
bio30-017	<small>Blood glucose</small><br><b>Effect on blood glucose</b><br><i>Insulin (β cells) · Glucagon (α cells)?</i>	<b>Insulin (β cells):</b> <b>Falls</b><br><b>Glucagon (α cells):</b> <b>Rises</b>	ImatPath Biology recall
bio30-018	<small>Blood glucose</small><br><b>Cause</b><br><i>Type 1 · Type 2?</i>	<b>Type 1:</b> <b>Autoimmune</b> destruction of β cells: <b>no insulin</b><br><b>Type 2:</b> <b>Insulin resistance</b> (target cells respond poorly), often with obesity	ImatPath Biology recall
bio30-019	<small>Blood glucose</small><br><b>Onset</b><br><i>Type 1 · Type 2?</i>	<b>Type 1:</b> Usually in childhood<br><b>Type 2:</b> Usually adults, increasing in younger people	ImatPath Biology recall
bio30-020	<small>Blood glucose</small><br><b>Treatment</b><br><i>Type 1 · Type 2?</i>	<b>Type 1:</b> <b>Insulin injections</b><br><b>Type 2:</b> Diet, exercise, drugs. Sometimes insulin	ImatPath Biology recall
bio30-022	<small>The principle</small><br><b>Stimulus</b>	a change in a variable (for example, body temperature rising).	ImatPath Biology key idea
bio30-023	<small>The principle</small><br><b>Receptor</b>	detects the change (thermoreceptors in the skin and hypothalamus).	ImatPath Biology key idea
bio30-024	<small>The principle</small><br><b>Control centre</b>	compares the value with the <b>set point</b> and decides the response (the <b>hypothalamus</b>, the pancreas).	ImatPath Biology key idea
bio30-025	<small>The principle</small><br><b>Effector</b>	carries out the response (sweat glands, muscles, liver).	ImatPath Biology key idea
bio30-026	<small>The principle</small><br><b>Response</b>	brings the variable back towards the set point.	ImatPath Biology key idea
bio30-027	<small>The principle</small><br><b>Negative feedback</b>	the response <b>reverses the change</b> and brings the variable <b>back to the set point</b>. This is how almost all homeostasis works (temperature, glucose, water). It produces small <b>oscillations</b> around the set point.	ImatPath Biology key idea
bio30-028	<small>Water and salt balance</small><br><b>Dehydration</b>	<b>osmoreceptors in the hypothalamus</b> detect it. The <b>posterior pituitary</b> releases <b>ADH (antidiuretic hormone)</b>. ADH makes the <b>collecting ducts more permeable to water</b> (by inserting <b>aquaporins</b>), so more water is reabsorbed: <b>small amount of concentrated urine</b>. You also feel <b>thirsty</b>.	ImatPath Biology key idea
bio30-029	<small>Water and salt balance</small><br><b>Too much water</b>	<b>less ADH</b> is released, so the collecting ducts reabsorb less water: <b>large amount of dilute urine</b>.	ImatPath Biology key idea
bio30-030	<small>Answers & explanations</small><br><b>ADH</b>	dehydration → more water reabsorbed, concentrated urine. <b>Aldosterone</b>: Na<sup>+</sup> retention.	ImatPath Biology key idea
bio30-009	Key points: <b>Feedback</b>	• Stimulus → receptor → control centre (set point) → effector → response.<br>• <b>Negative feedback</b> stabilises (most homeostasis). <b>Positive feedback</b> amplifies (childbirth, clotting).	ImatPath Biology summary
bio30-010	Key points: <b>Temperature</b>	• <b>Hypothalamus</b>. Hot: sweating, vasodilation. Cold: shivering, vasoconstriction. Fever = raised set point.	ImatPath Biology summary
bio30-011	Key points: <b>Glucose</b>	• High → <b>insulin</b> (uptake, glycogenesis). Low → <b>glucagon</b> (glycogenolysis, gluconeogenesis). <b>Type 1</b>: no insulin (autoimmune). <b>Type 2</b>: resistance.	ImatPath Biology summary
bio30-012	Key points: <b>Water and pH</b>	• <b>ADH</b>: dehydration → more water reabsorbed, concentrated urine. <b>Aldosterone</b>: Na<sup>+</sup> retention.<br>• Blood pH 7.35–7.45: <b>buffers</b>, lungs (CO<sub>2</sub>), kidneys.	ImatPath Biology summary
bio30-001	Which set of responses occurs when body temperature falls below the set point?<br><br><br>A) Vasodilation, sweating and flattened hair<br>B) Vasoconstriction in the skin, shivering and raised body hair<br>C) Vasodilation and shivering<br>D) Vasoconstriction and sweating<br>E) Sweating and shivering	<b>B) Vasoconstriction in the skin, shivering and raised body hair</b><br><br>The hypothalamus detects the fall in temperature. The effectors reduce heat loss (vasoconstriction, hair erection) and increase heat production (shivering, raised metabolic rate). Sweating and vasodilation are responses to heat. bio30-003	Which of these is an example of <b>positive</b> feedback?<br><br><br>A) Oxytocin increases uterine contractions, which release more oxytocin during labour<br>B) Insulin lowers blood glucose, which lowers insulin release<br>C) Sweating lowers body temperature, which reduces sweating<br>D) High blood CO<sub>2</sub> increases breathing, which lowers CO<sub>2</sub><br>E) Low blood calcium releases parathyroid hormone, which raises calcium	<b>A) Oxytocin increases uterine contractions, which release more oxytocin during labour</b><br><br>Positive feedback amplifies the change. In labour, contractions push the head against the cervix, which stimulates more oxytocin and stronger contractions until birth. The others are negative feedback loops that restore a set point.	ImatPath Biology practice
bio30-005	Blood pH is given by <i>pH = 6.1 + log([HCO<sub>3</sub><sup>-</sup>]/[CO<sub>2</sub>])</i>. With <i>[HCO<sub>3</sub><sup>-</sup>] = 24</i> mmol/L, what is the pH when dissolved CO<sub>2</sub> falls from 1.2 to 0.8 mmol/L (for example in hyperventilation)?<br><br><br>A) About 7.4<br>B) About 7.2<br>C) About 6.9<br>D) About 8.4<br>E) About 7.6	<b>E) About 7.6</b><br><br>At 1.2 mmol/L: <i>log 20 = 1.30</i>, pH <i>= 7.4</i>. At 0.8 mmol/L: ratio <i>= 30</i>, <i>log 30 = 1.48</i>, so pH <i>= 6.1 + 1.48 = 7.58</i>. Less CO<sub>2</sub> means less carbonic acid, so the blood becomes more alkaline.	ImatPath Biology practice
bio30-007	At the start of a fever a person feels cold and shivers, although their body temperature is above normal. Why?<br><br><br>A) The body cannot sense temperature<br>B) The set point is lowered<br>C) Shivering is a response to heat<br>D) The hypothalamic set point has been raised, so the body temperature is below the new set point<br>E) Negative feedback has stopped working	<b>D) The hypothalamic set point has been raised, so the body temperature is below the new set point</b><br><br>Pyrogens raise the hypothalamic set point. Since the actual temperature is lower than the new set point, the body responds as it would in the cold: vasoconstriction and shivering until the temperature reaches the new set point.	ImatPath Biology practice
