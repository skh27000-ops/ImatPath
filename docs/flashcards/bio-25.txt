bio25-013	<small>What is a mutation?</small><br><b>Chemical</b><br><i>Examples · How it acts?</i>	<b>Examples:</b> Tobacco-smoke compounds, <b>benzopyrene</b>, <b>nitrous acid</b>, base analogues<br><b>How it acts:</b> Alter or damage bases, or cause mispairing	ImatPath Biology recall
bio25-014	<small>What is a mutation?</small><br><b>Biological</b><br><i>Examples · How it acts?</i>	<b>Examples:</b> Some viruses (HPV, hepatitis B), <b>transposons</b><br><b>How it acts:</b> Insert into genes or disturb control	ImatPath Biology recall
bio25-015	<small>Mutations of a single gene</small><br><b>Silent</b><br><i>What happens · Effect on protein?</i>	<b>What happens:</b> New codon codes for the <b>same amino acid</b> (because the code is redundant)<br><b>Effect on protein:</b> <b>None</b>	ImatPath Biology recall
bio25-016	<small>Mutations of a single gene</small><br><b>Missense</b><br><i>What happens · Effect on protein?</i>	<b>What happens:</b> New codon codes for a <b>different amino acid</b><br><b>Effect on protein:</b> May change the shape and function (<b>sickle cell</b>: Glu → Val)	ImatPath Biology recall
bio25-017	<small>Mutations of a single gene</small><br><b>Nonsense</b><br><i>What happens · Effect on protein?</i>	<b>What happens:</b> New codon is a <b>stop codon</b><br><b>Effect on protein:</b> <b>Shorter</b> protein, usually non-functional	ImatPath Biology recall
bio25-018	<small>Mutations of chromosomes</small><br><b>Deletion</b><br><i>What happens · Example?</i>	<b>What happens:</b> A segment is lost<br><b>Example:</b> <b>Cri-du-chat syndrome</b> (deletion in chromosome 5)	ImatPath Biology recall
bio25-019	<small>Mutations of chromosomes</small><br><b>Duplication</b><br><i>What happens · Example?</i>	<b>What happens:</b> A segment is repeated<br><b>Example:</b> Can give extra gene copies	ImatPath Biology recall
bio25-020	<small>Mutations of chromosomes</small><br><b>Inversion</b><br><i>What happens · Example?</i>	<b>What happens:</b> A segment is reversed<br><b>Example:</b> Often no loss of genes	ImatPath Biology recall
bio25-021	<small>Mutations of chromosomes</small><br><b>Translocation</b><br><i>What happens · Example?</i>	<b>What happens:</b> A segment moves to a <b>non-homologous</b> chromosome<br><b>Example:</b> The <b>Philadelphia chromosome</b> (9;22) in <b>chronic myeloid leukaemia</b>	ImatPath Biology recall
bio25-022	<small>Mutations of chromosomes</small><br><b>Aneuploidy</b><br><i>What happens · Example?</i>	<b>What happens:</b> Extra or missing whole chromosomes (non-disjunction)<br><b>Example:</b> Trisomy 21	ImatPath Biology recall
bio25-023	<small>Mutations of chromosomes</small><br><b>Polyploidy</b><br><i>What happens · Example?</i>	<b>What happens:</b> Whole extra sets of chromosomes<br><b>Example:</b> Common in plants (wheat, bananas)	ImatPath Biology recall

bio25-009	Key points: <b>Basics</b>	• Mutation = permanent change in DNA. <b>Germline</b> (inherited) vs <b>somatic</b> (not).<br>• Causes: errors, <b>UV</b>, X-rays, chemicals, some viruses.	ImatPath Biology summary
bio25-010	Key points: <b>Types</b>	• <b>Point</b>: <b>silent</b> (same amino acid), <b>missense</b> (different), <b>nonsense</b> (stop).<br>• <b>Insertion / deletion</b>: not a multiple of 3 → <b>frameshift</b> (severe).<br>• Chromosomal: deletion, duplication, inversion, <b>translocation</b>, aneuploidy, polyploidy.	ImatPath Biology summary
bio25-011	Key points: <b>Effects</b>	• Harmful, neutral or beneficial (depends on the environment). Source of <b>new alleles</b> for evolution.<br>• <b>DNA repair</b> keeps mutation rates low. Faulty repair → cancer.	ImatPath Biology summary
bio25-001	In sickle cell disease the codon GAG (glutamic acid) becomes GUG (valine). How is this mutation classified?<br><br><br>A) Silent mutation<br>B) Missense point mutation<br>C) Nonsense mutation<br>D) Frameshift mutation<br>E) Deletion	<b>B) Missense point mutation</b><br><br>One base is substituted and the codon now codes for a different amino acid, so it is a missense mutation. A silent mutation would still code for glutamic acid, and a nonsense mutation would create a stop codon.	ImatPath Biology practice
bio25-003	A mutation caused by UV light in a skin cell leads to melanoma. Will the mutation be passed to the person's children?<br><br><br>A) No, because it is a somatic mutation<br>B) Yes, because all mutations are inherited<br>C) Yes, because skin cells make gametes<br>D) Only if the child has the disease<br>E) Yes, because it is a germline mutation	<b>A) No, because it is a somatic mutation</b><br><br>Only mutations in the germline (cells that give rise to gametes) are inherited. A mutation in a skin cell is somatic and affects only that cell and its descendants.	ImatPath Biology practice
bio25-005	Xeroderma pigmentosum patients are extremely sensitive to sunlight and develop skin cancers. Which repair system is defective?<br><br><br>A) DNA ligase in replication<br>B) Telomerase<br>C) Reverse transcriptase<br>D) The sodium-potassium pump<br>E) Nucleotide excision repair, which removes UV-induced pyrimidine dimers	<b>E) Nucleotide excision repair, which removes UV-induced pyrimidine dimers</b><br><br>UV light joins neighbouring pyrimidines (thymine dimers), distorting the helix. Nucleotide excision repair cuts out the damaged strand and fills the gap. If it is faulty, mutations accumulate and skin cancer develops.	ImatPath Biology practice
bio25-007	An intercalating agent such as acridine inserts between bases and causes extra bases to be added during replication. Which kind of mutation is it most likely to cause?<br><br><br>A) Silent<br>B) Missense only<br>C) Chromosome translocation only<br>D) Frameshift<br>E) None, because it is a repair enzyme	<b>D) Frameshift</b><br><br>The insertion or deletion of one or two bases changes the reading frame of all the codons that follow, so these mutations usually produce a non-functional protein.	ImatPath Biology practice
